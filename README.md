# 游戏助手键鼠解锁

让普通键盘也能使用 OPlus / 一加游戏助手的「键鼠映射」，支持 scrcpy UHID。

[下载 APK](https://github.com/FFDVDGD/oplus-keymap-anywhere/releases/latest) · [更新日志](CHANGELOG.md) · [反馈问题](https://github.com/FFDVDGD/oplus-keymap-anywhere/issues)

## 功能

- 解除游戏助手仅支持官方键盘的限制。
- 为指定游戏保持鼠标按下，避免停止移动后自动松开。
- 自定义手动松开和强制复位快捷键，支持键盘按键与鼠标侧键。
- 触摸卡住时，在模块首页一键松开并复位。

鼠标保持、快捷键和复位功能从 **1.3** 起提供。

## 使用条件

- 已 root，并安装支持 API 102 的 LSPosed。
- 设备的游戏助手自带「键鼠映射」，键盘能被 Android 识别为完整键盘。
- 仅适用于游戏助手原本支持键鼠映射的游戏，不扩大游戏支持范围。

已在 OPD2413、Android 16、游戏助手 **10.34.21** 上使用验证。模块不锁定游戏助手版本；其他版本可能需要适配。

## 安装

1. 下载并安装 APK。
2. 在 LSPosed 中启用「游戏助手键鼠解锁」，作用域选择「游戏助手」`com.oplus.games`。
3. 保存游戏进度后，重启游戏助手或设备。
4. 连接键盘，在游戏侧栏打开「键鼠映射」，按原有方式配置键位。

停用时，在 LSPosed 中禁用模块并重启游戏助手；也可以卸载模块。不要同时启用其他修改同一功能的模块。

## 鼠标与快捷键设置

打开模块应用：

- **保持鼠标按下**：选择需要启用的游戏，支持搜索，已选项置顶。
- **手动松开按键**：按下要绑定的键。在所选游戏中松开鼠标，下一次移动继续映射。
- **强制复位按键**：按下要绑定的键，触摸卡住时可快速复位。
- **强制松开并复位所有触摸**：首页直接执行复位，只针对游戏助手产生的键鼠映射触点，不更改设置。

点击绑定框中的「清除」可禁用对应快捷键。设置修改立即生效，无需重启游戏助手。

**绑定键仅在模块界面和启用键鼠映射的游戏中由模块独占，不再触发原有映射或前进、后退；其他应用不受影响。** 两个功能绑定同一按键时，优先执行强制复位。

## scrcpy

使用 UHID 模式连接键盘和鼠标：

```powershell
scrcpy --keyboard=uhid --mouse=uhid
```

仅需键盘时可省略 `--mouse=uhid`，支持 ADB 无线连接。默认 SDK 键盘模式不受支持。
